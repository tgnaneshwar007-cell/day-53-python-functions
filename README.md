# Day 53 — Python Functions

Today I practiced different ways of working with Python functions, including passing functions as arguments, passing lists to functions, handling multiple arguments, and using default arguments.

## Topics Covered

- Passing a function as a parameter to another function
- Passing lists to functions
- Processing elements of a list using a function
- Counting elements using a function
- Passing multiple arguments
- Default arguments

## Programs

### 1. Function as Parameter
Passed the result of one function as an argument to another function.

### 2. Function with List
Passed a list to a function and separated integer values from characters.

### 3. Counting List Elements
Used a function and loop to count the number of elements in a list.

### 4. Passing Multiple Arguments
Passed multiple values to a function and performed addition.

### 5. Default Arguments
Used a default value for a function parameter when no value was provided.

## Key Learning

Functions help organize code into reusable blocks and make programs easier to understand and maintain.
