# Day 53 — Python Functions & Recursion 🐍

This repository contains my **Day 53 Python technical practice** from my CRT learning journey.

Today's session focused on strengthening my understanding of **Python functions, function arguments, nested functions, and recursion** through simple practical programs.

## 📚 Topics Covered

### 1. Passing a Function Result as a Parameter

Learned how the returned value from one function can be passed as an argument to another function.

### 2. Passing Lists to Functions

Practiced passing a list as an argument and processing its elements inside a function.

### 3. Counting List Elements

Used a function and loop to count the number of elements in a list.

### 4. Passing Multiple Arguments

Practiced passing multiple values to a function and performing operations on them.

### 5. Default Arguments

Learned how a function parameter can have a default value when no argument is provided.

### 6. Function Inside Another Function

Practiced defining and calling an inner function inside an outer function.

### 7. Passing Function Results

Used the result returned by one function as an argument to another function.

### 8. Recursion

Learned how a function can call itself and how a base condition controls the recursion.

### 9. Infinite Recursion

Explored what happens when a recursive function has no proper stopping condition.

### 10. Decreasing Recursion

Practiced recursion by decreasing the value step by step.

### 11. Increasing Recursion

Practiced recursion by increasing the value step by step until the stopping condition is reached.

## 💡 Key Learning

The main takeaway from today's session was understanding how **functions improve code organization and reusability**, while recursion provides a different way of solving problems through repeated function calls.

I also understood the importance of a **base condition in recursion** to ensure that the recursive process eventually stops.
